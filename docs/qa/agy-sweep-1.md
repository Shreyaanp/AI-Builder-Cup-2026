# QA sweep 1 findings (Antigravity)

Audit of current main on git branch `fix/agy-qa-1` across owner flow (S1, S2, Close-the-day, S10 new-shop flow), customer flow (`customer-*`, S8 passport, search/ask), and Playwright test executions on phone (390×844) and desktop (1440×1000).

## 1. Automated Test Results

- `npx playwright test tests/stories --project=phone --reporter=line`: 34 tests total. 33 passed in initial batch run; 1 test (`tests/stories/a3.spec.ts:6:1 › A3 · independent customer context polls visible prices and availability`) timed out under concurrency load on Windows, but passed cleanly (1/1 passed in 26.7s) when rerun individually.
- `npx playwright test tests/qa -c tests/qa/playwright.config.ts --project=phone --reporter=line`: 88 tests total. 76 passed, 12 failed during high port churn due to dev server TIME_WAIT connection refusals. When rerunning the failing spec (`tests/qa/voice-continuity.spec.ts`), all 22 tests passed cleanly (22/22 passed in 1.3m).
- Frontend checks: `npx tsc -b` and `npx eslint src --max-warnings 0` both passed with 0 errors and 0 warnings.
- Backend checks: `ruff check app` (clean), `mypy app` (Success: no issues in 67 files), `pytest -q` (624 passed, 164 skipped, 0 failures).
