# Face check audit (Track G)

Run on 2026-10-16 against origin/main (`f36e2da`) on phone (Pixel 7, 412×839) and desktop
(1440×1000), Chrome with a fake camera, then against the live private worker. Screenshots of
the old flow are in [face-audit/](face-audit/); the fixed flow is in
`docs/stories/trust-{phone,desktop}-{light,dark}-*.png` (story test
`tests/stories/s12-trust.spec.ts`).

Short version: the check could never succeed. The worker kept templates in a per-instance
store that vanished on every scale-down, the on-device guidance engine never loaded, and the
result screen showed raw internal codes. Every issue below is fixed.

## Still open

- Liveness and match thresholds are not calibrated on a real population. A match only opens
  a human review.
- A full live `/evaluate` with the shared bearer and a real face was not run from a laptop
  (the bearer stays in Secret Manager). Run `backend/scripts/face_worker_smoke.py` against
  the container, or open the check once on production after deploy.
