### Key Root Causes & Architectural Recommendations

1. **Owner App Single URL Trap**: `AppShell` and `WorkspaceProvider` keep `destination` in plain `useState` on `/`. Navigating tabs does not call `pushState`. Changing `ws.go` to synchronize `?tab=shop|grow|you` with `history.pushState` and reading `location.search` on mount/popstate will restore tab history and reload retention.
2. **Missing Overlay Back Interceptors**: Overlays like Coach Actions (`+` menu), Choose Shop menu, and Customer `ProfileSheet`/`PlaceSearch` need to register with `useBackClose` (or customer history stack) so Back dismisses the active sheet instead of popping the window history.
3. **Customer Search & Filter History**: `AskHome` query submission should push `?q=<term>` so Back returns to the clean prompt and reload restores results. In `Discover.tsx`, category filters should push history instead of replacing it, allowing Back to return to the unfiltered list.
4. **Deep Link Fallback**: Pages loaded directly via external/shared deep link should detect empty in-app history (`!history.state?.inApp`) and handle Back by redirecting to `/explore/` or `/explore/browse` rather than allowing browser exit.
