# Bug hunt on main, 16 Oct 2026

Branch `fix/bughunt-main`, based on `main` with PR 47 merged in (7349b1f). Ports WEB 3801 / API 3901,
`RECALL_PATH=data/test-vectors`, `--workers=1`, everything run in the foreground. `tests/qa/**` was
not run or touched.

## What was run

- **Browser suite, desktop:** 310 tests in 61 files, run in four chunks so each stays under 10 minutes.
  Two failures, and both passed when their files were rerun alone (flakes 1 and 2 below). All other
  tests passed; the skipped ones are phone-only.
- **Browser suite, phone:** all files. Two failures, and both passed when their files were rerun
  alone (flakes 1 and 3).
- **Server log:** the dev server prints the browser's console errors, so I read them across both
  runs. Three kinds of error showed up. Each one is a finding below and is now fixed.
- **Click-through by hand at 360×780** with a short throwaway Playwright script on a Pixel 7 profile,
  as an Indian phone (`en-IN`, `Asia/Kolkata`):
  - owner onboarding by text, then the Today, Shop, Grow and You tabs
  - Close the day, then the rescue deal from Grow
  - customer: area step, Ask, answer, shop page, QR stamp

  No page scrolls sideways, no console errors, and prices show ₹. I also checked each screen's
  screenshot by eye.

- **Static checks and backend:** `npx tsc -b`, `npx eslint src --max-warnings 0`,
  `npx prettier --check .`, plus backend `ruff`, `mypy` and `pytest -q` (795 passed, 200 skipped).
  All clean.

Severity: 1 = blocks a core flow, 2 = wrong result or data, 3 = visible defect or console error with
a workaround, 4 = cosmetic or copy.
