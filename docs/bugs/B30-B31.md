## B31

- BusinessFields validates an integer target from 3 to 20, default 8. Both SQLite and Firestore use this shared model and public projection. Old records receive the default in the projection. The owner editor sends the target in the sealed proposal, and the confirmation view displays it before saving. The OpenAPI/TypeScript contract is regenerated.
- Cards render exactly N filled/empty circles, remaining stamps for the owner's reward, device-storage wording and an explicit no-sync/no-purchase-proof statement. Empty reward text has a truthful empty state and no claim action.
- Only a QR entry earns a stamp, at most once per shop calendar day. Full cards stop accumulating. Staff redemption resets the current count, increments the saved claim count and retains the last earning day. Existing local cards remain readable.
- Claim opens a full-screen, focus-managed redeem dialog showing shop name, reward, a seconds clock and date in the shop timezone. Close, Escape and browser Back dismiss it. The timer is cleaned up on dismissal. The clock helps staff inspect a live screen; neither it nor local storage establishes fraud resistance or staff authorization.
- New card, target and redemption strings are shared by customerCopy/customerLocales and the rewards dictionary for English, Simplified Chinese, Malay, Tamil, Japanese, Korean, Indonesian, Thai, Vietnamese and Filipino.
